# dr-exec PR 11 — fake executor, conformance, and execution pool

PR: https://github.com/danielle-rothermel/dr-exec/pull/11

Deferred review suggestions recorded on the PR, as standing todos:

- [ ] **Worker threads are never pruned from `_workers`.** The capacity cap compares against list length, and exited workers are never removed. Safe today only because a worker can exit solely from terminal conditions; any future idle-timeout or bounded-lifetime worker turns this into a starvation deadlock. Cheap hardening: count live workers.
- [ ] **Single-concurrent-stream refusal is an implementation-chosen restriction.** `run_stream` refuses a second concurrent stream because the ready queue carries no per-stream identity, which would make the context cast unsound. Nothing in the design asks for stream exclusivity; a per-stream tag on the completion would remove the need for the refusal. Worth confirming whether exclusivity is an intended v1 guarantee. (Related: the `_streaming` check-and-set is not lock-guarded — safe under the single-event-loop contract, unreachable otherwise.)
- [ ] **`__aexit__` chooses abort-on-exception.** Clean exit drains; an exception propagating out of the `async with` body aborts. The design specifies both operations but not which one context-manager exit selects, and the choice has durable consequences (in-flight work records `CancelledOutcome` instead of ordinary outcomes). Defensible, but worth recording as a standing contract line so it is not re-decided per task.
- [ ] **`_declaration` assumes a `Runtime` never rewrites the request.** The fake measures the *declared* request; the engine measures the request *after* `runtime.prepare()`. Identical for the one shipped runtime, but `Runtime` is a governed swappable Protocol that promises no such thing — a conforming runtime that rewrote the request would silently break input-budget parity. Either state the obligation on `Runtime.prepare` and back it with runtime conformance, or soften the docstring claim.
- [ ] **`run_many` discards everything but the slot count.** It resolves a full `EffectivePoolCapacity` and projects to `.max_active_jobs`, so a batch that ran AUTO on a 10-CPU machine is indistinguishable afterwards from one given FIXED(10). `ExecutionPool` exposes `effective_capacity`; the batch surface has nowhere to put it under its frozen signature.
- [ ] **Conformance suite darwin-marks whole cases, thinning ubuntu coverage.** `@requires_macos` sits on the test function, so it skips the `[fake]` half too — 28 of 40 cases deselect off-darwin, including fake-side cases needing no macOS. `tests/test_fake_executor.py` and `tests/test_execution_pool.py` recover most of the ground; what is lost is the *parity framing*. Mechanical fix: move the mark onto the process factory param.
- [ ] **No test pins the "no thread per unadmitted job" clause.** Queue entries, children, and lazy input are all covered; live worker threads are not. The implementation is correct — a coverage gap on an explicitly enumerated contract clause, closable in the same style as the existing token-retention case.
- [ ] **`drain()` discards already-finished completions when a consumer stops mid-stream.** Explicitly documented in `shutdown()` and `cancel_all()` docstrings and pinned by a test, so this is a stated limit rather than a silent one — recorded because it reads as a contract violation on first pass and a future reviewer will re-derive it.
- [ ] **Test substrate reaches into `CancelToken._wait`.** The right primitive (the alternative is polling, which the test rules forbid) and justified in the helper's docstring, but a private-name reach from shared test support couples the pool suites to a non-public method. If consumers writing gated fakes need the same thing, `_wait` is a candidate for deliberate promotion.
- [ ] **`_run_batch` uses `next(source, None)` as its exhaustion sentinel.** A `None` element would be indistinguishable from exhaustion. Unreachable for a well-typed caller, but `run_stream` gets this right via `StopAsyncIteration`, and a `sentinel = object()` would make the two loop shapes identical at zero cost.
- [ ] **`declared_input_bytes` is in `_declaration.__all__` with no caller outside its own module.** The engine derives stdin bytes through `_target_of` instead. Harmless (private module), but advertising a shared-path helper that is not shared invites a future agent to reach for it as the canonical accessor.
- [ ] **The fake half of `test_concurrent_calls_use_distinct_attempt_identities` is tautological.** The fake does not mint identities; the assertion verifies that `uuid4()` returns distinct values. The suite's own stated policy would narrow this case to production only, or drop it.
